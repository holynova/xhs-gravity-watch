# Gravity Court · 重力表盘

[用手机打开表盘](https://holynova.github.io/xhs-gravity-watch/)

用 Safari 或 Chrome 打开 HTTPS 页面。手机默认进入正面表盘，看到「启用体感」时轻点并允许访问。平放时重力在屏幕平面上的分量接近零，抬起手机的一侧，小球就会向较低的一侧滚动。支持横竖屏。右上角可切换为手腕视角，下方可切换网球、篮球、足球、水晶和金条。

桌面可直接打开 index.html，拖动或使用方向键改变重力。运动传感器需要支持的移动浏览器和安全上下文。提示文字会区分连接、等待、拒绝授权和缺少读数。

## 实现

纯静态 HTML、CSS、Canvas 2D 和 JavaScript，无构建步骤。方向事件换算为屏幕平面上的重力向量，加速度事件作为备用来源。碰撞模拟使用固定步长和圆角边界。水晶、金条以圆形包围体近似碰撞。固定显示的时间与原视觉参考对应。

参考小红书「三眼鱼石 DESIGN」收藏笔记《给 Apple Watch 做了一个物理互动表盘》和笔记署名的原作者 [@cabbitar](https://substack.com/@cabbitar)。手腕视角的摄影底图取自该参考画面，球场、材质和运动由网页实时绘制。
